# Contributing

This is a personal portfolio project, and I am not taking contributions:
pull requests and feature requests will be closed without review. You are
welcome to read the code, fork it under the MIT licence (LICENSE) and
reuse it, within the data terms in DATA_LICENSES.md.

If you find a security problem, or something in the repository that should
not be public, please open an issue that says only that you found one, and
I will get in touch. Do not put the details in the issue.
